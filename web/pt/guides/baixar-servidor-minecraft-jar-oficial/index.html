Baixar o servidor de Minecraft (jar oficial) e uma forma mais fácil

A Mojang publica de graça o servidor de Minecraft Java em um único arquivo, o server.jar. Baixar é a parte fácil; o que dá trabalho é o que vem depois: escolher o Java certo, aceitar o EULA, digitar comandos e manter tudo funcionando. Aqui estão as duas formas, manual e com um aplicativo.

Atualizado em 22 de outubro de 2026 · 6 min de leitura

Baixar o MC-ServerLauncher grátis

Onde baixar o servidor oficial

O site oficial é a página do servidor de Minecraft em minecraft.net (minecraft.net/download/server), que oferece o server.jar da versão mais recente. Para uma versão anterior, a Mojang publica um manifesto com todas elas e o hash (SHA-1) de cada arquivo, que é o que o MC-ServerLauncher usa. Desconfie de sites que oferecem um «servidor de Minecraft grátis» com instalador: o servidor da Mojang é um .jar e não precisa ser instalado.

Esse é o servidor vanilla: sem mods nem plugins. Se você quer algum deles, precisa de um servidor Fabric, Forge ou NeoForge (mods) ou Paper ou Purpur (plugins). Explicamos em como adicionar mods a um servidor de Minecraft.

Manualmente: executar o server.jar

  1. 1

    Instale o Java

    Cada versão do Minecraft pede um Java mínimo, e as recentes pedem Java 21 ou superior. Baixe um compatível e instale.

  2. 2

    Baixe o server.jar

    Salve em uma pasta vazia só para o servidor, por exemplo MeuServidor.

  3. 3

    Execute pela primeira vez

    Abra um terminal nessa pasta e execute java -Xmx2G -jar server.jar nogui. Ele cria os arquivos e para, pedindo que você aceite o EULA.

  4. 4

    Aceite o EULA

    Abra o eula.txt, troque eula=false por eula=true e salve. Com isso você aceita o EULA do Minecraft.

  5. 5

    Execute de novo

    Rode o mesmo comando. Ele gera o mundo e, quando o console mostrar «Done», você já pode entrar a partir desse mesmo PC com o endereço localhost.

Funciona, mas cada passo fica por sua conta: para os seus amigos entrarem você teria que abrir a porta 25565 no roteador, não há backups automáticos e, para trocar de versão, você repete o processo com outro arquivo.

Uma forma mais fácil: MC Server Launcher

O MC-ServerLauncher baixa esse mesmo servidor oficial, confere o hash, detecta o Java certo ou baixa para você, pede que você aceite o EULA e deixa o servidor pronto. Ele traz ainda console, backups, mods do Modrinth e um túnel para os seus amigos entrarem.

  1. 1

    Instale o aplicativo

    Baixe o instalador para Windows, o AppImage para Linux ou o DMG para macOS na seção de downloads desta página. Você não precisa ter o Java instalado.

  2. 2

    Crie o servidor

    Clique em «Novo» e em «Criar um novo», escolha o tipo (Vanilla é o servidor da Mojang como ele é) e a versão, marque «Aceito o EULA do Minecraft» e crie o servidor.

  3. 3

    Inicie

    Clique em «Iniciar» e olhe o console: quando ele indicar que o servidor está pronto, você já pode entrar pelo Minecraft com o endereço localhost.

  4. 4

    Compartilhe com os seus amigos

    Ative o túnel integrado e copie o endereço público, sem abrir portas. Os passos estão em como hospedar um servidor de Minecraft grátis sem abrir portas.

Dica

O servidor que o aplicativo cria é o mesmo server.jar da Mojang, em uma pasta normal do seu disco. Se mais tarde você preferir executá-lo manualmente, já sabe onde ele está.

Quando cada forma faz sentido

  • Manualmente, se você quer aprender como um servidor funciona ou precisa de uma configuração bem específica.
  • Com o aplicativo, se você quer tudo pronto em minutos, com backups, console e amigos entrando pela Internet.
  • Com um painel web, se o servidor vai ficar sempre ligado em uma máquina Linux e várias pessoas vão administrá-lo. Na comparação de gerenciadores de servidor de Minecraft para Windows estão as opções.
PERGUNTAS FREQUENTES

Dúvidas frequentes

Onde baixar o servidor de Minecraft de graça e com segurança?

Somente na página oficial do servidor em minecraft.net, ou com um aplicativo que baixe de lá e confira o hash, como o MC-ServerLauncher. Evite instaladores de sites desconhecidos: o servidor oficial é um arquivo .jar.

Qual versão do Java preciso para o server.jar?

Depende da versão do Minecraft: as recentes pedem Java 21 ou superior. O MC-ServerLauncher detecta o Java certo ou baixa para você.

Posso baixar uma versão antiga do servidor?

Sim. A Mojang publica todas as versões no manifesto dela. No MC-ServerLauncher você escolhe a versão ao criar o servidor e o aplicativo baixa o arquivo oficial correspondente.

O server.jar serve para Bedrock?

Não. O server.jar é o servidor de Minecraft Java. O Bedrock tem o próprio servidor. No MC-ServerLauncher, os jogadores de Bedrock entram em um servidor Paper ou Purpur com o Geyser, como explicado no guia do servidor grátis.

Posso colocar mods no server.jar da Mojang?

Não diretamente: o servidor vanilla não carrega mods. Você precisa de um servidor Fabric, Forge ou NeoForge; os passos estão no guia do servidor com mods.

O servidor de Minecraft é grátis?

Sim, baixar e executar não custa nada, embora você aceite o EULA do Minecraft. Para entrar e jogar, você precisa do Minecraft Java Edition.
