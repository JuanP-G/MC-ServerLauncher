ANLEITUNG

Minecraft-Server herunterladen (offizielle Jar) und ein einfacherer Weg

Mojang veröffentlicht den Minecraft-Java-Server kostenlos als einzelne Datei, die server.jar. Das Herunterladen ist der leichte Teil; mühsam ist alles danach: das richtige Java wählen, die EULA akzeptieren, Befehle tippen und den Server am Laufen halten. Hier sind beide Wege, von Hand und mit einer App.

Woher du den offiziellen Server lädst

Die offizielle Quelle ist die Minecraft-Server-Seite auf minecraft.net (minecraft.net/download/server), die die server.jar der neuesten Version anbietet. Für eine ältere Version veröffentlicht Mojang ein Manifest mit allen Versionen und der Prüfsumme (SHA-1) jeder Datei; genau das nutzt MC-ServerLauncher. Sei misstrauisch bei Seiten, die einen „kostenlosen Minecraft-Server“ mit Installer anbieten: Mojangs Server ist eine .jar und muss nicht installiert werden.

Das ist der Vanilla-Server: ohne Mods und ohne Plugins. Willst du sie, brauchst du einen Fabric-, Forge- oder NeoForge-Server (Mods) oder einen Paper- oder Purpur-Server (Plugins). Das erklären wir unter Mods zu einem Minecraft-Server hinzufügen.

Von Hand: die server.jar starten

  1. 1

    Java installieren

    Jede Minecraft-Version verlangt ein Mindest-Java, und neuere brauchen Java 21 oder höher. Lade ein passendes herunter und installiere es.

  2. 2

    Die server.jar herunterladen

    Speichere sie in einem leeren Ordner nur für den Server, zum Beispiel MeinServer.

  3. 3

    Beim ersten Mal starten

    Öffne ein Terminal in diesem Ordner und führe java -Xmx2G -jar server.jar nogui aus. Der Server legt seine Dateien an und hält an, weil du die EULA akzeptieren sollst.

  4. 4

    Die EULA akzeptieren

    Öffne eula.txt, ändere eula=false in eula=true und speichere. Damit akzeptierst du die Minecraft-EULA.

  5. 5

    Noch einmal starten

    Führe denselben Befehl aus. Er erzeugt die Welt, und sobald die Konsole „Done“ meldet, kannst du von demselben PC aus mit der Adresse localhost beitreten.

Das funktioniert, aber jeder Schritt liegt bei dir: Damit Freunde beitreten können, müsstest du den Port 25565 im Router freigeben, es gibt keine automatischen Backups, und für eine andere Version wiederholst du alles mit einer anderen Datei.

Ein einfacherer Weg: MC Server Launcher

MC-ServerLauncher lädt genau diesen offiziellen Server herunter, prüft seine Prüfsumme, erkennt das passende Java oder lädt es herunter, bittet dich, die EULA zu akzeptieren, und macht den Server startklar. Dazu kommen eine Konsole, Backups, Mods von Modrinth und ein Tunnel, damit deine Freunde beitreten können.

  1. 1

    Die App installieren

    Lade das Installationsprogramm für Windows, das AppImage für Linux oder das DMG für macOS im Download-Bereich dieser Seite herunter. Du brauchst kein Java installiert zu haben.

  2. 2

    Den Server erstellen

    Klicke auf „Neu“ und „Neu erstellen“, wähle den Typ (Vanilla ist Mojangs Server, so wie er ist) und die Version, setze den Haken bei „Ich akzeptiere die Minecraft-EULA“ und erstelle den Server.

  3. 3

    Ihn starten

    Klicke auf „Starten“ und beobachte die Konsole: Sobald sie meldet, dass der Server bereit ist, kannst du in Minecraft mit der Adresse localhost beitreten.

  4. 4

    Mit Freunden teilen

    Aktiviere den integrierten Tunnel und kopiere die öffentliche Adresse, ganz ohne Portfreigabe. Die Schritte stehen unter Minecraft-Server kostenlos hosten ohne Portfreigabe.

Tipp

Der Server, den die App erstellt, ist dieselbe server.jar von Mojang in einem normalen Ordner auf deiner Festplatte. Wenn du ihn später lieber von Hand startest, weißt du, wo er liegt.

Wann welcher Weg sinnvoll ist

  • Von Hand, wenn du lernen willst, wie ein Server funktioniert, oder eine ganz bestimmte Einrichtung brauchst.
  • Mit der App, wenn du ihn in Minuten startklar haben willst, mit Backups, Konsole und Freunden, die über das Internet beitreten.
  • Mit einem Web-Panel, wenn der Server dauerhaft auf einer Linux-Maschine laufen soll und mehrere Personen ihn verwalten. Im Vergleich von Minecraft-Server-Managern für Windows stehen die Optionen.
HÄUFIGE FRAGEN

Häufige Fragen

Wo lade ich den Minecraft-Server sicher und kostenlos herunter?

Nur auf der offiziellen Server-Seite von minecraft.net oder mit einer App, die ihn von dort lädt und seine Prüfsumme prüft, wie MC-ServerLauncher. Meide Installer von unbekannten Seiten: Der offizielle Server ist eine .jar-Datei.

Welche Java-Version brauche ich für die server.jar?

Das hängt von der Minecraft-Version ab: Neuere brauchen Java 21 oder höher. MC-ServerLauncher erkennt das passende Java oder lädt es für dich herunter.

Kann ich eine ältere Version des Servers herunterladen?

Ja. Mojang veröffentlicht alle Versionen in seinem Manifest. In MC-ServerLauncher wählst du die Version beim Erstellen des Servers, und die App lädt die passende offizielle Datei.

Funktioniert die server.jar für Bedrock?

Nein. Die server.jar ist der Minecraft-Java-Server. Bedrock hat einen eigenen Server. In MC-ServerLauncher treten Bedrock-Spieler einem Paper- oder Purpur-Server mit Geyser bei, wie es in der Anleitung zum kostenlosen Server steht.

Kann ich Mods auf Mojangs server.jar nutzen?

Nicht direkt: Der Vanilla-Server lädt keine Mods. Du brauchst einen Fabric-, Forge- oder NeoForge-Server; die Schritte stehen in der Anleitung zum Server mit Mods.

Ist der Minecraft-Server kostenlos?

Ja, Herunterladen und Starten kostet nichts, du akzeptierst aber die Minecraft-EULA. Zum Spielen brauchst du allerdings Minecraft Java Edition.
