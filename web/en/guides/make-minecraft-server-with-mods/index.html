How to add mods to a Minecraft server (or make a modded one from scratch)

A modded server comes down to four decisions: which server type, which version, which mods, and how your friends get them. This guide walks through them with MC-ServerLauncher, with no file editing and no commands.

Updated October 24, 2026 · 7 min read

First, pick the server type

A mod only works on the loader it was made for, so this is the one choice worth getting right. Fabric is light and gets new Minecraft versions quickly; Forge and NeoForge are home to the big content mods (machinery, dimensions, magic). If you already know which mods you want, check on their Modrinth page which loader and version they exist for, and pick the combination that covers all of them.

Paper and Purpur are no use for mods: they load plugins, which are a different thing and run on the server alone. If you want server improvements without your friends installing anything, use plugins; for new content inside the game, use mods.

Create the server with the app

  1. 1

    Install MC-ServerLauncher

    Download the installer for your system from the downloads section of this page. You don't need Java installed: the app finds it or downloads it for you.

  2. 2

    Create the server

    Click “New” and “Create a new one”. Give it a name, pick the type (Fabric, Forge or NeoForge) and the Minecraft version, tick “I accept the Minecraft EULA” and create the server. The app downloads the official files, checks their checksum and gets it ready.

  3. 3

    Install the mods

    Open the “Mods” tab, search Modrinth (results are already filtered by your version and server type) and click “Install”. The libraries a mod needs, such as Fabric API, are installed along with it.

  4. 4

    The memory adjusts itself

    The more mods, the more RAM, and the app takes that into account: it sets the maximum from your mods (4, 6 or 8 GB) and Java gives back the memory it does not use. If you would rather set it yourself, choose “Manual” under Configure → “Performance”.

  5. 5

    Start the server

    Click “Start” and watch the console: once it says the server is ready, you can join. Errors show up in red and the message usually names the mod that is failing.

Where to download Minecraft server mods

The safest source is Modrinth, and it is the one the app uses: each mod says which loader and Minecraft version it was made for, the app only shows the ones that fit your server, and it checks every download against its checksum. If you download mods by hand from a website, look at three things: that they are for your server's loader (Fabric, Forge or NeoForge), for the same Minecraft version, and that you also get their dependencies. A mod is code that runs on your computer, so avoid .jar files that come through Discord or from unknown sites.

To add them to a server you already have, open it in the app, go to the “Mods” tab and install them from there: no need to copy files. As on any server, you can also drop a .jar by hand into the server's mods folder and restart it. If your server is Vanilla or Paper, change its type in its settings first (the last question below explains how).

Get the mods to your friends

On a Fabric, Forge or NeoForge server, whoever joins usually needs the same mods as the server, with the same loader and the same Minecraft version. The app tells you on each mod whether it also has to be installed on the client, and it can build a mod pack for your friends: a zip with the mods they need and a script for Windows, Linux and macOS that copies them into their mods folder without deleting anything. Mods that only act on the server are left out automatically.

Tip

Before adding lots of mods at once, make a manual backup from the backups tab. The app already copies the world before starting and when stopping, but this way you can return to this exact point if a mod breaks something.

Let people join from the Internet

To play with friends who are not at your home you don't need to forward any router ports: the app includes a Playit.gg tunnel. FAQ

Common questions

How do I add mods to a Minecraft server?

Open the server in MC-ServerLauncher, go to the “Mods” tab, search for the mod on Modrinth and click “Install”; its dependencies are installed with it. The server must be Fabric, Forge or NeoForge, and the mod must be for the same Minecraft version. Restart the server so it loads the mod.

Which is better for mods: Fabric, Forge or NeoForge?

It depends on the mods you want. Fabric is lighter and usually updates first; Forge and NeoForge have the biggest content mods. A mod made for one loader doesn't work on another, so choose by looking at the list of mods you want to use.

Can I put mods on a Paper server?

No. Paper and Purpur load plugins, not Forge or Fabric mods. They are different systems and don't mix in the same folder.

Do my friends have to install the same mods?

In most cases yes, with the same loader and Minecraft version. Some mods only act on the server and aren't needed on the client: the app marks this on each result and leaves those mods out when it builds the pack.

How much RAM does a modded server need?

The app decides it by itself: it sets the maximum at 4 GB up to 30 mods, 6 GB up to 100 and 8 GB beyond that (a limit, not a reservation) and adjusts it to what your server really needs. If you would rather set it yourself, choose “Manual” under Configure → “Performance”; it applies on the next start.

Can I turn a server I already have into a modded one?

Yes. In the server settings, under “Type and version”, you can change the type (for example from Vanilla to Fabric). Back up the world first, just in case.

Is a modded server free?

Yes. MC-ServerLauncher is free and open source, and Modrinth, where the mods come from, is free too. The server runs on your own computer, so there is no subscription.
