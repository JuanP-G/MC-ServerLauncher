Download the Minecraft server (official jar) and an easier way

Mojang publishes the Minecraft Java server for free as a single file, server.jar. Downloading it is the easy part; what takes effort is everything after: picking the right Java, accepting the EULA, typing commands and keeping it running. Here are both ways, by hand and with an app.

Where the official server is downloaded from

The official place is the Minecraft server page on minecraft.net (minecraft.net/download/server), which offers the server.jar of the latest version. For an older version, Mojang publishes a manifest listing all of them with each file's checksum (SHA-1), which is what MC-ServerLauncher uses. Be wary of sites that offer a “free Minecraft server” with an installer: Mojang's server is a .jar and needs no installation.

This is the vanilla server: no mods and no plugins. If you want them, you need a Fabric, Forge or NeoForge server (mods) or a Paper or Purpur one (plugins). We cover it in how to add mods to a Minecraft server.

By hand: run the server.jar

  1. 1

    Install Java

    Each Minecraft version asks for a minimum Java, and recent ones need Java 21 or newer. Download a compatible one and install it.

  2. 2

    Download the server.jar

    Save it in an empty folder just for the server, for example MyServer.

  3. 3

    Run it the first time

    Open a terminal in that folder and run java -Xmx2G -jar server.jar nogui. It creates its files and stops, asking you to accept the EULA.

  4. 4

    Accept the EULA

    Open eula.txt, change eula=false to eula=true and save. That accepts the Minecraft EULA.

  5. 5

    Run it again

    Run the same command. It generates the world and, when the console says “Done”, you can join from that same PC using the address localhost.

It works, but every step is yours: for friends to join you would have to forward port 25565 on your router, there are no automatic backups, and to change version you repeat the process with another file.

An easier way: MC Server Launcher

MC-ServerLauncher downloads that same official server, checks its checksum, detects the right Java or downloads it, asks you to accept the EULA and leaves the server ready. It also brings a console, backups, Modrinth mods and a tunnel so your friends can join.

  1. 1

    Install the app

    Download the installer for Windows, the AppImage for Linux or the DMG for macOS from the downloads section of this page. You don't need Java installed.

  2. 2

    Create the server

    Click “New” and “Create a new one”, choose the type (Vanilla is Mojang's server as it is) and the version, tick “I accept the Minecraft EULA” and create the server.

  3. 3

    Start it

    Click “Start” and watch the console: when it says the server is ready, you can join from Minecraft using the address localhost.

  4. 4

    Share it with your friends

    Turn on the built-in tunnel and copy the public address, with no port forwarding. The steps are in how to host a free Minecraft server without port forwarding.

Tip

The server the app creates is the same Mojang server.jar, in a normal folder on your disk. If you later prefer to run it by hand, you know where it is.

When each way makes sense

  • By hand, if you want to learn how a server works or need a very specific setup.
  • With the app, if you want it ready in minutes, with backups, a console and friends joining from the Internet.
  • With a web panel, if the server will be on all the time on a Linux machine and several people will manage it. The comparison of Minecraft server managers for Windows lists the options.
FAQ

Common questions

Where do I download the Minecraft server safely and for free?

Only from the official server page on minecraft.net, or with an app that downloads it from there and checks its checksum, like MC-ServerLauncher. Avoid installers from unknown sites: the official server is a .jar file.

Which Java version do I need for the server.jar?

It depends on the Minecraft version: recent ones need Java 21 or newer. MC-ServerLauncher detects the right Java or downloads it for you.

Can I download an older version of the server?

Yes. Mojang publishes every version in its manifest. In MC-ServerLauncher you pick the version when you create the server and the app downloads the matching official file.

Does the server.jar work for Bedrock?

No. The server.jar is the Minecraft Java server. Bedrock has its own server. In MC-ServerLauncher, Bedrock players join a Paper or Purpur server with Geyser, as explained in the free server guide.

Can I put mods on Mojang's server.jar?

Not directly: the vanilla server doesn't load mods. You need a Fabric, Forge or NeoForge server; the steps are in the modded server guide.

Is the Minecraft server free?

Yes, downloading and running it costs nothing, although you accept the Minecraft EULA. To join and play you do need Minecraft Java Edition.
