GUIDE

Télécharger le serveur Minecraft (jar officiel) et une façon plus simple

Mojang publie gratuitement le serveur Minecraft Java dans un seul fichier, le server.jar. Le télécharger est la partie facile ; le plus long, c'est ce qui suit : choisir le bon Java, accepter l'EULA, taper des commandes et le garder en marche. Voici les deux façons, à la main et avec une appli.

Mis à jour le 22 octobre 2026 · 6 min de lecture

Où télécharger le serveur officiel

Le site officiel est la page du serveur Minecraft sur minecraft.net (minecraft.net/download/server), qui propose le server.jar de la dernière version. Pour une version plus ancienne, Mojang publie un manifeste qui les liste toutes avec l'empreinte (SHA-1) de chaque fichier, et c'est ce qu'utilise MC-ServerLauncher. Méfie-toi des sites qui proposent un « serveur Minecraft gratuit » avec installateur : le serveur de Mojang est un .jar et n'a pas besoin d'être installé.

C'est le serveur vanilla : sans mods ni plugins. Si tu en veux, il te faut un serveur Fabric, Forge ou NeoForge (mods) ou Paper ou Purpur (plugins). On l'explique dans comment ajouter des mods à un serveur Minecraft.

À la main : lancer le server.jar

  1. 1

    Installe Java

    Chaque version de Minecraft demande un Java minimum, et les récentes demandent Java 21 ou plus. Télécharge-en un compatible et installe-le.

  2. 2

    Télécharge le server.jar

    Enregistre-le dans un dossier vide réservé au serveur, par exemple MonServeur.

  3. 3

    Lance-le une première fois

    Ouvre un terminal dans ce dossier et exécute java -Xmx2G -jar server.jar nogui. Il crée ses fichiers et s'arrête en te demandant d'accepter l'EULA.

  4. 4

    Accepte l'EULA

    Ouvre eula.txt, remplace eula=false par eula=true et enregistre. Tu acceptes ainsi l'EULA de Minecraft.

  5. 5

    Relance-le

    Exécute la même commande. Il génère le monde et, quand la console affiche « Done », tu peux te connecter depuis ce même PC avec l'adresse localhost.

Ça marche, mais chaque étape est pour toi : pour que tes amis entrent, il faudrait ouvrir le port 25565 sur ta box, il n'y a pas de sauvegardes automatiques et, pour changer de version, tu refais tout avec un autre fichier.

Une façon plus simple : MC Server Launcher

MC-ServerLauncher télécharge ce même serveur officiel, vérifie son empreinte, détecte le bon Java ou le télécharge, te demande d'accepter l'EULA et prépare le serveur. Il apporte aussi une console, des sauvegardes, les mods de Modrinth et un tunnel pour que tes amis puissent entrer.

  1. 1

    Installe l'appli

    Télécharge l'installateur pour Windows, l'AppImage pour Linux ou le DMG pour macOS dans la section téléchargements de cette page. Tu n'as pas besoin d'avoir Java installé.

  2. 2

    Crée le serveur

    Clique sur « Nouveau » puis « En créer un nouveau », choisis le type (Vanilla est le serveur de Mojang tel quel) et la version, coche « J'accepte l'EULA de Minecraft » et crée le serveur.

  3. 3

    Démarre-le

    Clique sur « Démarrer » et regarde la console : quand elle indique que le serveur est prêt, tu peux te connecter depuis Minecraft avec l'adresse localhost.

  4. 4

    Partage-le avec tes amis

    Active le tunnel intégré et copie l'adresse publique, sans ouvrir de ports. Les étapes sont dans héberger un serveur Minecraft gratuit sans ouvrir de ports.

Astuce

Le serveur que crée l'appli est le même server.jar de Mojang, dans un dossier normal de ton disque. Si tu préfères le lancer à la main plus tard, tu sais où il est.

Quand choisir chaque façon

  • À la main, si tu veux comprendre comment fonctionne un serveur ou si tu as besoin d'une configuration très précise.
  • Avec l'appli, si tu le veux prêt en quelques minutes, avec sauvegardes, console et amis qui entrent depuis Internet.
  • Avec un panel web, si le serveur doit tourner en permanence sur une machine Linux et être géré par plusieurs personnes. Le comparatif des gestionnaires de serveur Minecraft pour Windows liste les options.
QUESTIONS FRÉQUENTES

Questions courantes

Où télécharger le serveur Minecraft gratuitement et en sécurité ?

Uniquement sur la page officielle du serveur sur minecraft.net, ou avec une appli qui le télécharge de là et vérifie son empreinte, comme MC-ServerLauncher. Évite les installateurs de sites inconnus : le serveur officiel est un fichier .jar.

Quelle version de Java faut-il pour le server.jar ?

Ça dépend de la version de Minecraft : les récentes demandent Java 21 ou plus. MC-ServerLauncher détecte le bon Java ou le télécharge pour toi.

Puis-je télécharger une ancienne version du serveur ?

Oui. Mojang publie toutes les versions dans son manifeste. Dans MC-ServerLauncher, tu choisis la version en créant le serveur et l'appli télécharge le fichier officiel correspondant.

Le server.jar fonctionne-t-il pour Bedrock ?

Non. Le server.jar est le serveur Minecraft Java. Bedrock a son propre serveur. Dans MC-ServerLauncher, les joueurs Bedrock rejoignent un serveur Paper ou Purpur avec Geyser, comme expliqué dans le guide du serveur gratuit.

Puis-je mettre des mods sur le server.jar de Mojang ?

Pas directement : le serveur vanilla ne charge pas de mods. Il te faut un serveur Fabric, Forge ou NeoForge ; les étapes sont dans le guide du serveur avec mods.

Le serveur Minecraft est-il gratuit ?

Oui, le télécharger et le lancer ne coûte rien, même si tu acceptes l'EULA de Minecraft. Pour jouer, il te faut en revanche Minecraft Java Edition.
